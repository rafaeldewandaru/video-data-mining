### Overview

This project builds a visual perception system that **detects and tracks multiple objects** across image sequences extracted from video. Two object classes are targeted:

- **Orange Ball** (`ball`)
- **Blue Cup** (`cup`)

Three datasets with increasing complexity are provided:

| Dataset | Contents |
|---------|----------|
| **A – Orange Ball** | Frames containing a single orange ball |
| **B – Blue Cup** | Frames containing a single blue cup |
| **C – Mixed** | Frames with both objects under complex conditions (occlusion, random motion, re-entry) |

---

### Approach

#### Object Detection using YOLOv8s

YOLOv8s (Small) is fine-tuned on the combined Dataset A + B using transfer learning from COCO pretrained weights. The model predicts bounding boxes and class labels in a single forward pass at the native 320×240 frame resolution. The Small variant is chosen for its inference speed and compact model size, which are the priorities for per-frame real-time tracking.

Training strategy:
- 80/20 train/val split preserving temporal order (no data leakage)
- 50 epochs with early stopping (`patience=10`)
- `imgsz=320` to match native resolution

#### Multi-Object Tracking using BoT-SORT

**BoT-SORT (Bag-of-Tricks SORT)** extends vanilla SORT with three improvements that address its failure modes on this dataset:

1. **Two-stage matching cascade** (ByteTrack-style): High-confidence detections are matched first, then low-confidence detections which are normally discarded rescue unmatched tracks in a second pass, preserving continuity during occlusion.
2. **Global Motion Compensation (GMC)**: A sparse optical flow corrects Kalman predictions against scene-wide camera motion before matching, therefore reducing drift.
3. **Appearance features / ReID (optional)**: Visual embeddings from a CNN can be used for long-range re-identification.

BoT-SORT is available via `model.track(tracker="botsort.yaml")` in the Ultralytics API, no manual Kalman filter, Hungarian algorithm, or track-state management required.

### How to Setup

1. Create a virtual environment using Python 3.12
```
python3.12 -m venv .venv
```

2. Activate the virtual environment
```
source .venv/bin/activate
```

3. Install required packages
```
pip install -r requirements.txt
```

4. Open and run `notebooks/video_mining.ipynb` from top to bottom. It will download the data, prepare the YOLO dataset, train the model, run inference on all three datasets, evaluate detection and tracking metrics, and render output videos.
